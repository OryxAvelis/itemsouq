# Itemsouq brand mark

The `itemsouq-mark.svg` asset is the primary Itemsouq symbol.

- Concept: a game fruit combined with a marketplace bag.
- Moroccan cue: the eight-point zellige rosette and red/green accents.
- Primary tile: `#6D4AFF`; availability green: `#18C77A`; accent red: `#EF4B58`.
- Wordmark: `ITEMSOUQ` in Manrope 800 with the descriptor `FRUITS MARKET`.
- Minimum digital size: 32 px. Use the full wordmark beside it whenever space allows.
- The symbol is an original Itemsouq asset and does not reproduce Roblox or Blox Fruits branding.
